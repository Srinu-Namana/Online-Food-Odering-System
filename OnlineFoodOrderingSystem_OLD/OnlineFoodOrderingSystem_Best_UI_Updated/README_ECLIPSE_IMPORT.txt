ONLINE FOOD ORDERING SYSTEM

Tomcat: 11
Jakarta Servlet API: 6.1.0
MySQL Connector/J: 9.6.0
Java: 17

ECLIPSE IMPORT:
1. Extract the ZIP.
2. Eclipse > File > Import > General > Existing Projects into Workspace.
3. Select the extracted OnlineFoodOrderingSystem folder.
4. Select Apache Tomcat v11.0 under Targeted Runtimes.
5. Project Facets: Dynamic Web Module 6.0, Java 17.
6. Project > Clean.
7. Add the project to Tomcat 11.
8. Run:
   http://localhost:8080/OnlineFoodOrderingSystem/

DATABASE:
Run database/food_ordering_db.sql in MySQL.
